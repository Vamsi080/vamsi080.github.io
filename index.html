about me

Building software where performance is critical

I'm Vamsi Mikkili, an Embedded Software Engineer based in Chennai, specialising in Modern C++, Qt/QML and Qt WebAssembly for real-time embedded and defence systems.

I design and build complete solutions, from responsive QML operator interfaces to multi-threaded C++ backends that talk directly to hardware over RS-422/232, SPI, I2C, UART and TCP/UDP. I've delivered radar HMIs, telemetry systems and manufacturing tools for DRDO-DGRE, DRDO-NSTL and INS Valsura.

I care about clean, maintainable code. I profile with QML Profiler, Valgrind and GDB to keep applications fast and leak-free, and I mentor junior engineers through code reviews in Agile teams.
